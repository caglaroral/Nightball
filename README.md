# Nightball

A Haxball-style 2D football game for players on the same Wi-Fi. No server needed: one device
hosts a room and the others find it on the local network and join.

There are two versions in this repository:

- **`godot/`**: the current version, built with Godot 4.7.
- **`core/`, `lwjgl3/`, `android/`**: the first version, built with libGDX (Java). It still
  builds, but new work happens in the Godot version.

## Godot version

Requires the Godot 4.7 editor (the commands below assume it is at `~/Godot/godot`).

```bash
~/Godot/godot --path godot                    # run the game
~/Godot/godot --path godot --editor           # open the project in the editor
~/Godot/godot --headless --path godot -s res://tests/run_tests.gd   # run the tests
godot/tools/export_all.sh                     # build Windows, Linux and Android packages into dist/
```

Two windows on one computer:

```bash
~/Godot/godot --path godot -- --name Ali --host --start
~/Godot/godot --path godot -- --name Veli --join 127.0.0.1
```

`--start` starts the match as soon as the second player joins.

Controls: arrow keys or WASD to move, X or Space to kick. On phones, the left half of the screen
is a joystick (it appears where your thumb lands); hold anywhere on the right half to kick.

| Path | Contents |
|---|---|
| `scripts/physics` | Disc physics ported from Haxball's `game-min.js` |
| `scripts/game` | Match rules, stadium, snapshots |
| `scripts/net` | UDP protocol, room discovery, host and client sessions |
| `scripts/ui`, `scenes` | Screens, field rendering, touch controls, effects |
| `ui/theme.tres` | Buttons, cards and fonts. Generated by `tools/build_theme.gd`; editable in the Godot editor. |
| `assets/sfx` | Sound effects synthesised by `tools/make_sounds.py` |
| `assets/fonts` | Inter (SIL Open Font License) |
| `tools/capture.gd` | Saves screenshots of every screen, including a goal celebration |

The Android package is signed with the Android debug key. That is enough for sharing with
friends; publishing on the Play Store needs a separate release key.

## Physics

The physics follow the formulas extracted from Haxball's `game-min.js`. Every tick (1/60 s) each
disc moves, then its velocity is damped (`v = (v + gravity) * damping`), then collisions are
resolved. A bounce uses the product of both objects' `bCoef`. Player and ball defaults match
Haxball's.

## Networking

- Room discovery: UDP port 47777 (broadcast). Game traffic: UDP port 47778 (a random port if
  47778 is taken).
- The host is authoritative: physics run only on the host, at 60 Hz. Clients send their input;
  the host sends the full match state every tick. Clients draw 3 ticks behind the newest state
  and blend between states for smooth movement.
- If a room does not show up in the list, join with the address shown on the host's lobby screen.
  Guest networks and routers with "AP isolation" enabled stop devices from seeing each other.

## Sharing builds on the local network

```bash
python3 serve_dist.py            # serves dist/ at http://<this computer's IP>:8000/
```

Phones and computers on the same Wi-Fi can open that address in a browser and download the
packages. Installing the APK requires allowing installs from unknown sources on the phone.

The Windows package needs no Java or other runtime. On first launch, Windows Firewall asks for
network access: allow it on private networks, or room discovery will not work. Because the exe
is unsigned, SmartScreen may show an "Unknown publisher" warning ("More info" → "Run anyway").

## libGDX version

| Module | Contents |
|---|---|
| `core` | The whole game: physics, match rules, networking, UI |
| `lwjgl3` | Desktop launcher (Windows / Linux / macOS) |
| `android` | Android launcher. Only built when an Android SDK is configured. |

```bash
./gradlew lwjgl3:run                      # run on desktop
./gradlew lwjgl3:jar                      # single runnable jar in lwjgl3/build/libs/
./gradlew lwjgl3:packageWinX64            # Windows zip with a bundled Java runtime, in dist/
./gradlew android:assembleDebug           # needs sdk.dir in local.properties or ANDROID_HOME
./gradlew core:test
```

Two windows on one computer:

```bash
java -jar lwjgl3/build/libs/Nightball-0.1.0.jar --host --start --name Ali
java -jar lwjgl3/build/libs/Nightball-0.1.0.jar --join 127.0.0.1 --name Veli
```

The Windows package is built with [Construo](https://github.com/fourlastor-alexandria/construo).
jlink runs from the build machine's JDK, so the Windows JDK version in `lwjgl3/build.gradle` must
match the major version of the JDK used for the build (21).
